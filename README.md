# Algorith Voice — Desktop App (Public Releases)

Push-to-talk voice dictation for macOS, Windows, and Linux. Hold a hotkey, speak, text appears in the focused app.

> **This repo hosts public downloads only.** Active development happens in the private `algorithco/algorithvoice` monorepo. Issues and pull requests are disabled here.

## Download

Grab the latest installer from [**Releases**](https://github.com/algorithco/algorithvoice-app/releases/latest):

| OS | File | Notes |
|---|---|---|
| macOS (Apple Silicon) | `*_aarch64.dmg` | Requires macOS 13+ |
| macOS (Intel) | `*_x64.dmg` | Requires macOS 13+ |
| Windows | `*_x64.msi` | Requires Windows 10 1809+ (WebView2) |
| Linux | `*.AppImage` / `*.deb` | Ubuntu 22.04+ |

## Quick start

1. Install for your OS from Releases.
2. Open Algorith Voice, create an account or sign in.
3. Hold the hotkey (default `Ctrl+Space`), speak, release — text is typed where your cursor is.
4. Local offline mode works out of the box. Cloud transcription is opt-in.

## Privacy

Local mode = audio never leaves your device. Cloud STT and sync are opt-in and off by default. No telemetry without explicit consent.
